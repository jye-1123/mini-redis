# Redis 학습 노트

Redis를 이해하기 위해 함께 공부한 개념·비교·예시를 정리한 개인 필기입니다. 실행 가능한 프로젝트나 확정 설계의 기준 문서가 아닙니다.

## 읽는 순서

[학습 목차](study/00-overview.md)에서 필요성 → 키·값과 캐시 → 해시 테이블 → TTL → 서버·동시성 → 메모리·영속성 → 선택에서 배운 점 → 검증 방법 순서로 읽습니다.

## 실제 프로젝트

설계·요구사항·API·테스트 계획과 향후 코드는 개인 저장소 [main](https://github.com/jye-1123/mini-redis/tree/main)에서 관리합니다. [프로젝트 문서 지도](https://github.com/jye-1123/mini-redis/blob/main/docs/README.md)를 확인하세요. 현재 구현·제품 테스트는 아직 진행하지 않았습니다.

study-jye는 학습 필기, main은 실제 프로젝트입니다. 노트의 예시·과거 검토안이 최신 제품 규격을 대신하지 않습니다.

# Mini Redis

키로 값을 찾는 원리부터 만료·동시 요청·외부 API까지, 작은 인메모리 저장소를 만들기 위한 학습과 설계 기록입니다.

**현재 상태:** 사전 학습·설계 정리 단계. 실행 가능한 저장소와 API는 아직 없습니다.

## 프로젝트 개요

Mini Redis는 여러 프로그램이 같은 서버에 접속해 문자열 값을 저장·조회·삭제하는 저장소를 목표로 합니다. 해시 테이블을 직접 구현하고, 값의 보관 기간과 무효화, 동시 요청을 다룹니다. 외부 프로그램에서 응답을 재사용하는 예제를 통해 정확성과 성능을 확인할 예정입니다.

실제 Redis의 모든 기능을 재현하지 않습니다. 현재 합의한 환경은 **C · Windows · MSVC**, 외부 인터페이스는 **HTTP API**입니다. HTTP 서버 라이브러리와 API 경로·응답 형식은 아직 정하지 않았습니다.

## 기록의 기준

개념을 설명하는 예시와 실제 동작하는 기능을 구분합니다. 설계 선택에는 이유와 한계를, 테스트에는 입력·기대 결과·실제 결과를 남깁니다. 현재 문서의 테스트 목록은 **검증 계획**이며 테스트 통과나 성능 개선의 증거가 아닙니다.

일반적인 Redis의 동작과 Mini Redis의 구현 범위도 구분합니다. 학습을 정리한 뒤 기능별 조건과 필수 테스트를 함께 확정하고 구현을 진행합니다.

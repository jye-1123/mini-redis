# Mini Redis 프로젝트 개요

해시 테이블로 문자열 키·값을 저장하고, 여러 프로그램이 HTTP API로 사용하는 메모리 저장소를 만듭니다. 이 문서는 프로젝트 범위와 앞으로 제공할 사용 안내를 정리합니다.

## 목표

- 직접 만든 해시 테이블로 저장·조회·삭제를 제공
- TTL이 지난 값은 반환하지 않고, 접근하지 않는 만료 항목도 회수
- 같은 이벤트 루프에서 요청과 만료 작업을 처리
- 외부 앱의 응답 캐싱 예제로 사용성과 성능을 확인

## 환경과 현재 상태

| 항목 | 상태 |
| --- | --- |
| 언어·개발 환경 | C, Windows 네이티브, MSVC |
| 외부 인터페이스 | HTTP API 사용 확정 |
| 서버 라이브러리·API 규격 | 미정 |
| 저장 엔진·서버 구현 | 아직 없음 |
| 빌드·기능·부하 테스트 | 아직 실행하지 않음 |
| 영속성 | 선택 기능, 구현 없음 |

실제 Redis와 동일한 명령 프로토콜이나 모든 자료형을 지원하지 않습니다. 현재 계획은 문자열 기반 저장소이며, 자세한 선택과 한계는 [설계 기록](../study/07-project-decisions.md)에 있습니다.

## 사용 방법

실행 가능한 버전이 생기면 실제로 확인한 빌드·시작·종료 명령, HTTP 요청과 예상 응답, 입력 제한, 오류 동작을 여기에 추가합니다. 현재 문서의 개념 예시는 실행 안내가 아닙니다.

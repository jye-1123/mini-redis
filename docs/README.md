## 문서의 역할

`study/`는 왜 필요한지와 어떻게 동작하는지를 예시로 설명합니다. `docs/`는 과제 범위, 현재 구조, 결정 상태와 검증 기준을 정리합니다. 학습 문서에서 설명한 대안을 모두 구현한다는 뜻은 아닙니다.

선택 상태와 근거는 [설계 선택 문서](DECISIONS.md)에 모읍니다. 개념 설명이 길어져도 구현자가 미정 항목을 찾기 어렵지 않도록 합니다. 확정된 숫자도 실측 전에는 최적값이라고 부르지 않습니다.

테스트는 아직 계획입니다. 구현 후에는 실제 입력·명령·로그·판정을 기록하고 해당 설계나 학습 문서에서 연결합니다. 문서가 존재한다는 이유로 구현 완료나 개인의 숙련을 주장하지 않습니다.
